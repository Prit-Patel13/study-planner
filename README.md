# 📚 Study Planner

A full-stack Study Planner application built using React, Node.js, Express.js, and MongoDB Atlas. The application helps students organize, track, and manage their study tasks efficiently.

## 🚀 Live Demo

### Frontend

https://study-planner-2s1s.onrender.com

### Backend API

https://study-planner-api-ichs.onrender.com

---

## ✨ Features

* Add new study tasks
* Update task status
* Delete tasks
* View all tasks
* Search tasks
* Filter tasks by status
* Track study progress
* Responsive user interface
* Cloud database using MongoDB Atlas

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Prit-Patel13/study-planner.git
cd study-planner
```

### Backend Setup

```bash
npm install
```

Create a `.env` file:

```env
MONGO_URL=your_mongodb_connection_string
PORT=8000
```

Run backend:

```bash
npm start
```

### Frontend Setup

```bash
cd study-planner-frontend
npm install
npm run dev
```
